# 안압케어 — 녹내장 통합관리 (GLAUCOMA TOTAL APP)

녹내장 환자의 **안압 · 점안 · 전자문진 · 워치 헬스**를 하나의 앱에서 관리하고, 의미 있는 데이터를 의료진 웹으로 전달하는 통합 관리 시스템입니다. C&V Tech의 안압계 **CVT200**과 연동됩니다.

하나의 코드베이스에서 **환자 앱**과 **의료진 웹** 두 화면을 제공합니다.

## 핵심 설계

### 1. 좌·우안 선택 측정 · 좌우안 개별 점안

안압은 우안 / 좌안 / 양안 중 선택해 측정하며, 양안 선택 시 우안 → 좌안 순서로 진행됩니다. 점안 역시 좌·우안을 각각 체크해 한쪽만 넣은 경우도 정확히 기록됩니다.

### 2. 그래프 형식 선택

| 형식 | 표현 | 용도 |
|---|---|---|
| **Chart** | 날짜별 평균 라인 + 일중 최소~최대 밴드 | 장기 추세 |
| **Scatter** | 개별 측정값을 점으로 표시 | 분포와 이상치 |
| **Diurnal** | 0~24시 축에 겹쳐 표시, 야간 구간 음영 | 하루 중 안압 리듬 |

양안 / 우안 / 좌안 필터와 조합할 수 있습니다.

### 3. 순응도는 실제 점안 기록에서 계산

점안 1회를 1행으로 하는 기록 테이블(`DOSE_LOG`)에서 모든 순응도 수치를 집계합니다. 하드코딩된 퍼센트는 사용하지 않습니다.

```
{ date, medId, med, ingr, time, eye, taken, at }
```

집계 함수: `overallAdherence` / `adherenceByMed` / `adherenceBySlot` / `adherenceByEye` / `adherenceByDow` / `missStreak`
안압 추세 생성기도 같은 일별 순응도를 참조하므로, 점안 누락일에 안압이 오르는 관계가 한 소스에서 나옵니다.

### 4. 기기 소유 형태 이원화

| 구분 | 병원 대여 | 개인 소유 |
|---|---|---|
| 자산 | 기관 소유, 기간 대여 | 환자가 직접 구입 |
| 관리 항목 | 대여 시작일 · 반납 예정일 | 연동일 |
| 종료 처리 | 반납 처리 → 대여 가능 복귀 | 연동 해제 |

### 5. 알림 자동화 (2종)

**기기 반납** — D-3 안내 → D-1 알림 → 당일 → 연체 경고 → 유예 3일 초과 시 측정 데이터 수신 중단. 수신 중단 상태에서도 환자 앱 로컬 저장은 유지되며, 반납·연장 시 일괄 재전송됩니다.

**점안 순응도** — 최근 14일 순응도와 연속 누락으로 4단계 판정.

| 단계 | 조건 | 사전 알림 | 재알림 | 보호자 | 의료진 |
|---|---|---|---|---|---|
| 양호 | 90% 이상 | — | — | — | — |
| 주의 | 90% 미만 | 30분 전 | — | — | — |
| 경고 | 80% 미만 | 30분 전 | 15분 × 1회 | — | — |
| 위험 | 70% 미만 / 연속 3일 | 45분 전 | 15분 × 2회 | ○ | ○ |

특정 시각의 순응도가 85% 미만이면 그 시각만 15분 더 일찍 알립니다. 보호자 알림은 환자 동의가 있어야 발송됩니다.

모든 발송은 자동/수동 구분과 처리자를 남기는 감사 로그에 기록됩니다.

## 기술 스택

- **React 18** + **Vite 5**
- **Recharts** — 안압 추세·산점도·일중 변동·순응도 병렬 차트
- **lucide-react** — 아이콘
- **Tailwind CSS** (CDN) — 레이아웃 유틸리티

현재 버전은 프런트엔드 프로토타입으로 모든 데이터가 클라이언트 상태로 관리됩니다. 서버 구현을 위한 설계 문서는 `docs/`에 있습니다.

| 문서 | 내용 |
|---|---|
| [backend-architecture.md](docs/backend-architecture.md) | 시스템 구성, 테넌시, 인증·인가, 측정 수집, 국가별 규제, 보안, 배치 |
| [db-schema.md](docs/db-schema.md) | PostgreSQL 스키마 DDL, ERD, 인덱스, 집계 전략, 보존 정책 |
| [api-spec.md](docs/api-spec.md) | REST API 엔드포인트, 요청·응답 예시, 오류 코드, 레이트리밋 |
